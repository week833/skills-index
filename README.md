# 專案總覽

依用途整理金融研究、簡報文件與 Windows 桌面自動化專案。

## 金融與量化研究

| 專案 | 用途 | 型態 |
|---|---|---|
| [stock](https://github.com/week833/stock) | 股票研究環境整合、安裝與外部來源整理 | 研究工具與安裝包 |
| [finmind-twstock-research-skill](https://github.com/week833/finmind-twstock-research-skill) | 使用 FinMind 資料進行台股查詢規劃與研究 | Codex 研究 Skill |
| [ai-trader](https://github.com/week833/ai-trader) | AI 代理交易平台與模擬交易研究 | 研究 Fork |
| [stock-mitake-ui-reference](https://github.com/week833/stock-mitake-ui-reference) | 三竹股市介面導航與操作參考 | 參考文件 |

## AI 簡報與文件製作

| 專案 | 用途 | 型態 |
